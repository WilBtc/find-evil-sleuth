## `docs/ACCURACY.md`

Honest self-assessment, structured:

- **Confirmed findings:** N
- **Refuted findings:** N (validator caught hallucinations — list them)
- **Inconclusive:** N
- **Known misses (vs SANS solution):** specific artifacts the agent didn't surface, with hypothesis why
- **False positives observed during dev:** with PR links / commits showing how each was fixed

Judges value honesty here — copy a few real misses into this doc, don't claim 100%.

## `submission/execution-log.ndjson`

Generated by `scripts/export-execution-log.sh`. One JSON object per line, types:

- `obs_event` — every event posted to agent-obs:8910
- `tool_call` — full row from tool_calls hypertable
- `finding` — full row from findings
- `validation_run` — every validator pass
- `self_correction` — every retry attempt

Sorted by `started_at`. One file. Greppable. Judges score audit-trail criterion against this artifact.
